HOW TO PLAY
🔹 Fill every row with 1–9.
🔹 Fill every column with 1–9.
🔹 Each 3×3 box needs 1–9.
🔹 Never repeat a number in a row, column or box.
🔹 Use notes to remember possible numbers.
💡 PRO TIP
Start with a row, column or box that has the most numbers filled in. Look for the missing number before guessing.
